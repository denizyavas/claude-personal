Privacy Policy

Last updated: October 17, 2026

Claude Personal is a personal tool used only by its developer to access their own Google account.

Data accessed

With the user's consent, the app accesses Gmail, Google Calendar and Google Drive data through Google APIs.

How data is used

Data is processed on the user's own computer only to answer the user's requests. It is not sold, shared with third parties, or used for advertising.

Storage

OAuth tokens are stored locally on the user's computer. The app does not operate its own servers and does not store Google user data elsewhere.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
